# Meiki 0.2.0

Meiki 0.2 completes the simplify-and-harden release line for the personal,
network-free desktop application.

## Release metadata

- Application version: **0.2.0**
- Database schema: **11**
- `.meiki` archive version: **4**

An existing v0.1 schema-7 collection is backed up and migrated automatically.
Meiki continues to import published archive versions 1 through 4; new exports
use version 4.

## User-visible changes

- Clean installations remain empty and language-neutral until the first cloze
  is created.
- Study queues honor exact due timestamps, persist across restarts, and recover
  idempotently after a lost command response.
- Automatic scheduling is led by a daily study-time budget, with optional deck
  overrides and clearly separated expert controls.
- Collection and deck workflows are smaller and consistent across Today,
  Library, authoring, Settings, export, import, backup, and restore.
- The desktop interface now uses shadcn-svelte components, responsive
  navigation, light and dark themes, visible focus, and explicit dialog focus
  behavior.
- Production learning media is limited to application-managed local objects;
  remote media sources and network permissions remain outside product scope.

## Reliability and verification

- Real integration journeys exercise Rust application services, SQLite,
  scheduling, text, media, archives, backups, restore, and desktop command
  boundaries.
- Deterministic suites cover scheduler reference parity, lifecycle invariants,
  exact time and time-zone behavior, migrations, hostile archives and media,
  Unicode and IME events, responsive UI states, and storage-backed performance.
- Linux, macOS, and Windows package workflows build platform bundles, verify
  checksums, and smoke-launch a clean packaged application.

and [data portability](../data-portability.md) for archive compatibility.
